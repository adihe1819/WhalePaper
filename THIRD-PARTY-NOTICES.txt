WhalePaper third-party notices
==============================

WhalePaper itself contains no third-party runtime libraries.

Runtime platform
----------------
Microsoft .NET Framework 4.8 and Windows Presentation Foundation (WPF)
are Windows components by Microsoft Corporation.
Video playback uses Windows Media Foundation, a Windows component.

Development/build tools (not shipped to users)
----------------------------------------------
Inno Setup 6.0.5 (https://jrsoftware.org/isinfo.php) was used to build the
installer. Inno Setup is not included in the installed application.
innoextract 1.9 was used only to unpack the compiler for local building.

Fonts
-----
The application uses fonts already installed with Windows
(Microsoft YaHei UI, Segoe UI, Segoe MDL2 Assets).

Images
------
The application icon and default wallpaper are original assets generated
for this project. The sample media files under samples/ are test-only and
are not included in the installer.

No third-party media or runtime libraries are bundled with the application.
