# 1.0.7

本版本修复动态视频无法显示首帧，以及新版 Windows 桌面图标被播放窗口遮挡的问题。

## 修复

- 补齐 Media Foundation COM 继承接口的原生方法表，解决 sample 缓冲区转换失败。
- 使用真实帧 stride / pitch 处理方向与行复制，修正 RGB24 DIB 行对齐。
- 按媒体时间戳播放，高帧率源在 30fps 绘制上限下保持正常速度。
- 调整新版 Windows 的透明桌面图标层准备和宿主位置，使动态画面显示在图标后方。
- 媒体探测在解码失败或零帧时返回非零退出码，补充 seek 后继续解码和真实 COM 缓冲区检查。

## 验证与限制

已在 Windows 11 25H2 上验证视频/GIF 解码与绘制、视频循环、暂停恢复、实际桌面图标可见；用户确认图标可以正常选中。正常退出恢复原壁纸已验证。

视频仍静音，动态画面只在主显示器播放。锁屏、全屏、电池、远程会话、Explorer 重启和安装/升级/卸载等场景尚未完整验收。详见[验证记录](testing.md)。
