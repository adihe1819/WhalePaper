# WhalePaper 1.0.8

本版处理快速落雪等视频中的两个问题：普通播放只绘制 30fps，文件循环时 seek 和重新解码首帧会留下可见停顿。

解码线程现在复制 RGB 帧到有界队列后立即释放 MF sample；显示线程按同一个连续时钟播放，seek 发生时使用预取帧。RGB 复制缓冲最多 64 帧、512MiB，包含解码和显示中的帧。后台帧调度优先使用高精度 waitable timer，创建或等待失败时回退普通等待。

绘制调度上限提高到 240fps，并修复源帧率约为 240.00384 时错误回退至 30fps 的元数据处理。实际显示能力取决于解码、色彩转换、GDI、系统负载和刷新率；240fps 不是设备性能承诺。

同一播放实现的开发构建在一个 Windows 11 桌面、2560×1440 / 120fps 雪景素材上，连续观察到 23 次循环、绘制回调约 120fps、无丢帧及预取耗尽，P95 回调间隔约 8.63ms、循环最大间隔约 8.87ms。此结果属于单一环境，回调频率不等同于屏幕实际刷新，也不代表其他素材或系统通过。重新打包的发布程序应按[测试说明](testing.md)复核。

希望使用网页或全屏应用时仍保持连续运行，可关闭“设置 → 全屏应用时暂停”。默认设置及电池、锁屏、休眠、远程会话策略仍保留。
